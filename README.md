# 微处理器与嵌入式系统考试复习

[在线练习](https://corele-one.github.io/wq-exam-practice/)

104道分章填空题、23道汇编程序填空题，配套练习册与参考答案PDF。支持答案核对、解析、收藏、待复习筛选、草稿、进度导入导出和四套计时专项练习。P19-P23以C调用汇编为主线，从数组、位操作和字符串任务练习接口迁移。

题目按2026版课程讲义、课堂复习、课件、往届参考题与三次实验编排，来源说明保留在每题下方。此仓库只包含练习成品，未包含课本、课件原件、课堂记录或实验工程。练习题不能预测考试。

## 使用

打开网页即可作答。答案与草稿保存在当前浏览器；设备之间迁移请先导出备份，再导入。打开解析不自动计为掌握。自动核对是参考答案匹配，不运行用户代码；等价写法可对照解析自评。

下载：[练习册](pdf/微处理器_填空与编程练习册.pdf) · [参考答案与解析](pdf/微处理器_参考答案与解析.pdf)

## 发布

GitHub Pages 发布源为main分支根目录，`.nojekyll`关闭Jekyll处理。网页、题库与样式均内嵌于index.html，不依赖外部服务。

本地原项目的output/practice/build_pages.py用于同步发布成品。更新后只提交本目录的成品即可。
